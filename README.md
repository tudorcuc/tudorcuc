## ♘ Highlighted Projects

### [Scenify - Plan Scenic Routes](https://github.com/tudorcuc/scenify)
A fullstack web app (Python Flask + React) for route planning between two locations, offering the shortest path and exploration options with relevant tourist attractions. It uses complex algorithms like Traveling Salesman Problem, analyzes geographic data from OpenStreetMap/OSRM, applies filters and scoring for attraction selection, and provides three tailored route options. The user-friendly interface integrates OpenLayers for intuitive map visualization.

### [FP Unit](https://github.com/tudorcuc/Floating-Point-Calculation-Unit)
Floating-Point-Calculation-Unit is a VHDL project designed to handle precise floating-point calculations. This project simplifies complex arithmetic operations, providing accurate results.
